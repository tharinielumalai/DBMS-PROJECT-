HOSTEL LUGGAGE MANAGEMENT & SLOT ALLOCATION SYSTEM

Files:
- hostel_luggage.sql: MySQL 8.4 schema, sample data, constraints and triggers.
- index.html: responsive front-end prototype.

IMPORTANT:
1. The SQL file drops and recreates the hostel_luggage database. It will erase the current project database if you run it. Use only if you are comfortable resetting.
2. To run the SQL: open the .sql file in MySQL Workbench and execute the full script. If Workbench has trouble with DELIMITER, run the script from the MySQL command-line client instead.
3. To run the website: double-click index.html or open it in a browser.
4. The website is a self-contained front-end demo. Its actions are stored in browser memory and are NOT connected to MySQL. A Node.js backend/API is required for real persistence and multi-user sharing.
5. DEMO password values in SQL are placeholders, not usable credentials.
